# Release Notes: Sublime Security Splunk SOAR App v1.0.0

The Splunk SOAR Community is pleased to announce the initial release of the Sublime Security SOAR App (v1.0.0). This connector enables integration with the Sublime Security Platform API, allowing security operations center teams to automate email security operations, analysis, and response workflows.

## Key Features

- **Comprehensive API Coverage**
  Integrates with all key aspects of the platform API, including messaging, rules, hunt jobs, lists, mailboxes, and tasks.

- **Inbound Webhook Handler**
  Exposes a dedicated REST handler endpoint to receive events from the platform. It automatically provisions SOAR containers and extracts details into granular CEF artifacts.

- **Advanced Binary and Link Analysis**
  Provides automated binary submission via BinExplode and link evaluation via machine learning link analysis, including automatic capture of page screenshots directly into the SOAR Vault.

- **Full Vault Lifecycle Support**
  Any action that takes or outputs raw file data seamlessly interoperates with Splunk SOAR Vault IDs. This includes automated handling for EML downloads, rendered message images, and attachment previews.

- **Organizational List Management**
  Supports full list synchronization, entry lookups, and bulk ingestion workflows utilizing CSV formatted data from the SOAR Vault.

- **Identity Management Integration**
  Includes full SCIM user provisioning capabilities to manage user lifetimes, access controls, and attributes directly through automation playbooks.
